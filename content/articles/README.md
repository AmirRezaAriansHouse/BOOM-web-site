# اضافه‌کردن مقالهٔ جدید به مجله

۱. یک فایل `.md` جدید در همین پوشه (`content/articles/`) بساز، مثلاً `nutrition-tips.md`

۲. بالای فایل، این بخش frontmatter رو با اطلاعات مقاله‌ی خودت پر کن:

```yaml
---
title: "عنوان مقاله"
excerpt: "یک یا دو جمله معرفی کوتاه که زیر عنوان و توی کارت‌ها نشون داده می‌شه"
date: "۱۴۰۴/۰۷/۰۱"
category: "دسته‌بندی (مثلاً تغذیه، آمادگی جسمانی، حرکات اصلاحی)"
image: "assets/images/gallery/nutrition-cover.webp"
---
```

۳. زیر همون خط `---` دوم، متن مقاله رو با فرمت Markdown بنویس (##  برای تیتر، **بولد**، لیست با `-` و ...).

۴. یک‌بار (فقط بار اول) پکیج‌های لازم رو نصب کن:

```
npm install
```

۵. برای ساخت صفحات مقاله این دستور رو بزن:

```
npm run build
```

این دستور همهٔ فایل‌های `.md` داخل `content/articles/` رو می‌خونه و این‌ها رو خودکار می‌سازه/به‌روز می‌کنه:

- `articles/<نام-فایل>.html` — یک صفحه‌ی HTML ثابت برای هر مقاله (title، description، canonical، Open Graph و JSON-LD مخصوص همون مقاله)
- `magazine.html` — کارت‌ها و «جدیدترین مقاله»
- `sitemap.xml` — تاریخ `lastmod` از فیلد `date` گرفته می‌شه، یا اگه بخوای از فیلد اختیاری `updated: "۱۴۰۴/۰۷/۰۵"`

⚠️ پوشه‌ی `articles/`، فایل `sitemap.xml` و بخش‌های بین `BUILD:...` در `magazine.html` رو دستی ویرایش نکن؛ با build بعدی از بین می‌رن. نام فایل `.md` (یا فیلد `slug`) آدرس مقاله می‌شه، پس فقط حروف انگلیسی، عدد و خط تیره بذار و بعد از انتشار عوضش نکن.

۶. بعد از build، کل پروژه (به‌جز `node_modules/`) رو روی هاست/گیت‌هاب آپلود کن.
